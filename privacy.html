개인정보처리방침

이 방침은 운영자 본인의 Google 계정을 사용하는 개인용 Hermes Drive와 이 공개 안내 사이트에 적용됩니다.

1. 운영자와 문의

운영 계정은 hwwwaani입니다. 앱 운영 문의는 GitHub 문의 게시판에서, 계정 연결에 관한 문의는 Google 동의 화면에 표시된 사용자 지원 이메일로 할 수 있습니다. 공개 문의에는 개인 자료나 인증정보를 첨부하지 않습니다.

2. 접근하는 정보와 목적

  • Drive: 파일 식별자·이름·형식·수정 시각·소유자 등 검색 및 개별 조회 결과, 원문 링크, 명시적으로 요청한 다운로드 파일 내용.
  • Calendar: 일정 제목·식별자·시작과 종료·설명·장소·상태·원문 링크. 기본 브리핑에서는 오늘의 기본 캘린더를 조회합니다.
  • 인증: 연결 계정 식별 정보와 OAuth 인증정보. 사용자 계정으로 Google API에 접근하기 위해 사용합니다.
  • 작업 기록: 사용자 요청, 도구 조회 결과, 생성 보고서와 실행 상태. 작업 수행과 오류 확인에 사용합니다.

Google 자료는 사용자가 요청하거나 승인한 일정·문서 조회와 개인 업무 보고에 사용합니다. 이 앱의 기능에는 광고, 자료 판매, 모델 학습 작업이 포함되어 있지 않습니다.

3. 권한과 조회 범위

Google 권한은 drive.readonly와 calendar.readonly입니다. 이 권한 자체는 특정 폴더나 캘린더에 한정되지 않으므로, 실제 호출은 필요한 자료와 기간으로 좁힙니다. 파일·일정 변경 및 Gmail 접근은 이 Google 연결에서 제공하지 않습니다.

4. 처리와 전달

  • Google: 계정 연결과 원본 Drive·Calendar 조회.
  • Hostinger의 Hermes 서버: 인증정보 보관, 자료 조회, 작업 기록과 보고서 생성 과정.
  • 사용자 관리 기기: 역할별 업무 수행에 필요한 조회 결과·보고서·검증 파일 처리.
  • OpenAI: 연결된 AI 서비스로서 요청과 필요한 조회 내용을 받아 요약·분석.
  • Slack: 사용자가 지정한 대화로 보고서를 전달하고 기록을 보관. 해당 대화를 볼 수 있는 구성원은 보고서도 볼 수 있습니다.

외부 서비스에 전달된 자료에는 각 서비스 및 사용자 계정의 데이터 처리·보관 설정이 적용됩니다. Google 읽기 전용 권한은 조회 결과의 AI 처리나 Slack 보고서 포함을 막는 기능이 아닙니다.

5. 저장과 보관

인증정보는 서버의 별도 인증 저장 경로에 보관합니다. 요청·조회 결과·응답은 Hermes 대화 기록에, 다운로드와 역할별 검증 자료는 작업 파일에, Slack 보고서는 해당 채널 기록에 남을 수 있습니다.

이 앱은 위 자료 전체에 대한 일괄 자동 삭제나 고정 만료 기능을 제공하지 않습니다. 운영자가 작업·오류 확인에 필요한 동안 보관하며 직접 삭제합니다. 외부 서비스의 기록과 백업은 해당 서비스의 보관·삭제 설정을 별도로 따릅니다.

6. 연결 해제와 삭제

Google 계정의 타사 연결 관리에서 Hermes Drive의 접근 권한을 해제할 수 있습니다. 연결을 중단할 때에는 관련 예약 작업 중지와 서버 인증정보 제거도 별도로 수행합니다.

연결 해제만으로 기존 대화·작업 파일·Slack 보고서가 지워지지는 않습니다. 기록 삭제는 대상 기간과 자료 범위를 지정해 운영자에게 요청하거나, 운영자 본인이 Hermes·작업 저장소·Slack에서 각각 처리합니다. 백업 또는 외부 서비스 기록의 삭제 여부는 해당 서비스에서 별도로 확인합니다. 삭제 완료로 보고하기 전에 실제 삭제 범위를 확인합니다.

7. 공개 안내 사이트

이 사이트에는 로그인·자료 업로드·문의 폼·방문 분석 스크립트·외부 글꼴이 없으며, Google 계정 자료를 가져오는 기능도 없습니다. GitHub Pages에서 정적 HTML을 제공하며, 호스팅 접속정보에는 GitHub의 개인정보 처리방침이 적용됩니다.

8. 변경

사용 권한, 처리 경로 또는 제공 기능이 바뀌면 이 방침과 앱 안내를 갱신합니다. Google 자료 사용은 사용자에게 설명한 기능과 승인 범위 안에서 이루어져야 합니다.
